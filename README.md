## Описание проекта

Программа — двумерная аркадная игра «Астероиды» на Python и pygame. Игрок управляет кораблём на тороидальном поле: поворачивается, ускоряется и стреляет ракетами по астероидам. Реализованы заставка, жизни и очки, сопротивление среды, взрывы и полупрозрачный движущийся фон.

---

## Функциональные возможности

### Основной функционал

- Стартовый экран с жизнями (3), очками (0), неподвижным космосом и полупрозрачным слоем обломков, который едет влево
- Заставка по центру; партия начинается **только** по клику мыши по прямоугольнику заставки
- Корабль в центре поля: поворот вокруг центра, тяга по направлению носа, выстрел из носа
- Смена спрайта корабля при включённом двигателе
- Сопротивление среды: без тяги корабль постепенно останавливается
- Тороидальная геометрия поля (выход за край — появление с противоположной стороны)
- Случайные линейная и угловая скорости астероидов; камни друг с другом не сталкиваются
- Ракеты с ограниченным временем жизни — не пересекают поле по короткой стороне
- Столкновение ракеты с астероидом: взрыв, +1 очко
- Столкновение корабля с астероидом: взрыв, возрождение в центре, −1 жизнь
- При нуле жизней снова показывается заставка, счёт и жизни остаются на экране

### Дополнительный функционал

- Модульные тесты математики (тор, столкновения, время жизни ракеты)
- Параметры игры вынесены в `src/config.py` и прокомментированы

## Требования к системе

- **Python:** 3.9 или выше
- **Операционная система:** Windows / macOS / Linux
- **Библиотеки:** `pygame==2.6.1` (см. `requirements.txt`)

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/murbyasha/asteroids.git
cd asteroids
```

### 2. Создание и активация виртуального окружения

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

macOS / Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск программы

```bash
python main.py
```

### 5. Управление

| Клавиша | Действие |
| --- | --- |
| Стрелка влево | Поворот против часовой стрелки |
| Стрелка вправо | Поворот по часовой стрелке |
| Стрелка вверх | Двигатель (ускорение) |
| Пробел | Выстрел ракетой |
| ЛКМ по заставке | Начать / перезапустить игру |

Клик по полю **вне** прямоугольника заставки игнорируется.

## Структура проекта

```text
asteroids/
├── .gitignore
├── README.md
├── requirements.txt
├── main.py
├── assets/
│   └── images/          # фон, корабль, астероид, ракета, взрыв, заставка
├── src/
│   ├── __init__.py
│   ├── app.py           # окно и главный цикл
│   ├── assets.py        # загрузка картинок
│   ├── config.py        # глобальные параметры игры
│   ├── models/
│   │   ├── __init__.py
│   │   ├── vector.py    # векторная математика
│   │   ├── sprite.py    # базовый движущийся объект
│   │   ├── game_objects.py  # корабль, астероид, ракета, взрыв
│   │   └── game_model.py    # состояние партии
│   ├── renderers/
│   │   ├── __init__.py
│   │   └── renderer.py  # отрисовка кадра
│   └── widgets/
│       ├── __init__.py
│       ├── splash.py    # заставка и проверка клика
│       └── hud.py       # жизни и очки
└── tests/
    ├── __init__.py
    └── test_model.py    # тесты математики
```

**Назначение основных модулей:**

- `main.py` — точка входа
- `src/app.py` — класс `App`: окно, события, цикл
- `src/config.py` — все числовые параметры с комментариями
- `src/models/game_model.py` — логика партии без отрисовки
- `src/renderers/renderer.py` — фон, спрайты, HUD
- `src/widgets/splash.py` — клик только по заставке
- `tests/test_model.py` — проверка тора, столкновений и ракет

Структура следует рекомендованной в технических требованиях схеме `app / models / renderers / widgets / tests`. Игровая логика отделена от pygame-отрисовки, чтобы тесты математики не зависели от окна.

## Пример использования

```bash
python main.py
```

1. На заставке видны Lives: 3 и Score: 0, космос и движущиеся обломки.
2. Кликните по надписи RiceRocks / CLICK TO START.
3. Уворачивайтесь от астероидов, стреляйте пробелом.
4. После трёх столкновений снова появится заставка, счёт сохранится.

Запуск тестов:

```bash
python -m unittest discover -s tests -v
```

## Объектно-ориентированное проектирование

- `Vector2` — позиция и скорость
- `Sprite` — общее движение и круговой хитбокс
- `Ship`, `Asteroid`, `Missile`, `Explosion` — наследники `Sprite`
- `GameModel` — жизни, очки, спавн, столкновения
- `Renderer`, `Splash`, `HUD`, `App` — представление и ввод

Астероиды намеренно **не** сталкиваются друг с другом и свободно пересекаются.
